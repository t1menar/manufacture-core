# ADR-0011. Базовая безопасность

Статус: принято, 2026-11-10.

**Решение.**
- Один admin-токен (`MF_ADMIN_TOKEN`, ≥ 32 символов): Bearer или cookie `mf_session` (HttpOnly, SameSite=Strict). Если токен не задан, ядро генерирует его при первом старте, пишет хеш в БД и выводит токен один раз.
- По умолчанию слушается `127.0.0.1`.
- Секреты в спеке передаются только ссылками.
- Для модулей в кластере: отдельные пользователи брокера и проверка `user_id`.
- Для Kubernetes: Role только в namespace модулей, `runAsNonRoot`, allowlist образов.

**Пересмотр.** Многопользовательский доступ и OIDC, когда понадобятся.

# ADR-0002. Подключаемый runtime-драйвер

Статус: принято, 2026-11-10.

**Контекст.** Модули — Docker-образы. Нужен один локальный старт без Kubernetes и прод-путь в Kubernetes.

**Решение.** Интерфейс `runtime.Driver` (Apply, Delete, Status, Logs) и три реализации:
- `docker` (Docker Engine API, по умолчанию локально);
- `kubernetes` (Deployment на модуль, HPA/KEDA);
- `external` (модуль запущен где угодно, статус по heartbeat).

Controller сверяет желаемое состояние из БД с фактическим.

**Альтернативы.** Только Kubernetes: тяжёлый локальный старт. Оператор и CRD: не работают без кластера.

**Последствия.** `docker.sock` равен root на хосте, поэтому docker-драйвер предназначен только для локальной машины.

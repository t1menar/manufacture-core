# ADR-0007. Контекст запуска и большие данные

Статус: принято, 2026-11-10.

**Решение.**
- У run есть `data` (JSON) и выходы шагов `steps.<id>.output`.
- Шаг получает `data` или свою проекцию `input` (CEL).
- При `merge: data` выход применяется к `data` как JSON Merge Patch (RFC 7396). Конфликт ключей между параллельными шагами — ошибка, если не задан `join.merge`.
- Значения больше 64 КиБ SDK кладёт в S3/MinIO под `blob_prefix` попытки и передаёт объектом `{"$blob": "s3://…", "size", "sha256", "content_type"}` (claim-check).
- Ключ называется `$blob`, а не `$ref`, чтобы данные не путались с JSON Reference.
- Ядро хранит только ссылки, а снапшоты контекста — после каждой стадии.

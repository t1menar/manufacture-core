# ADR-0008. Наблюдаемость и живые данные

Статус: принято, 2026-11-10.

**Решение.**
- Обязательные метрики `mf_*` считает ядро по переходам шагов, поэтому они есть для любого модуля. Экспорт на `/metrics` (Prometheus).
- Трейсы OpenTelemetry идут через `traceparent` в конверте.
- Админка получает живые события по SSE `GET /api/v1/stream` (resume через `Last-Event-ID`) и раз в секунду `metrics.tick` из скользящих окон в памяти, поэтому Prometheus для неё не обязателен.
- Источник событий — таблица `events` и `pg_notify`.

**Альтернативы.** WebSocket: команды и так идут через REST, а SSE проще и проходит через прокси.

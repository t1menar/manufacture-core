# ADR-0001. Один бинарник с ролями engine, controller и gateway

Статус: принято, 2026-11-10.

**Контекст.** Ядро должно подниматься одной командой и сразу отдавать админку. Нагрузка измеряется десятками задач в минуту, данные общие (одна БД).

**Решение.** Модульный монолит: `manufacture serve --roles=engine,controller,gateway` (по умолчанию все роли). Роли изолированы пакетами и общаются через БД и шину, а не через вызовы функций друг друга. admin-api v1 вливается в gateway, админка встраивается через `go:embed`.

**Альтернативы.** Отдельные микросервисы: лишние сетевые контракты и деплой без выигрыша на этом масштабе.

**Последствия.** В Kubernetes роли можно разнести по Deployment флагом. Фоновые циклы берут лидерство через advisory-lock, поэтому реплик может быть несколько.

**Пересмотр.** Если одной роли понадобится иной цикл релизов или масштабирования.

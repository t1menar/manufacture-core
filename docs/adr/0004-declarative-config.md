# ADR-0004. Конфигурация: YAML-спек и БД как хранилище ревизий

Статус: принято, 2026-11-10.

**Решение.**
- Один формат: документы `apiVersion: manufacture.dev/v1` вида `Module` и `Pipeline` (`schemas/v1`).
- Одно хранилище: таблицы ревизий в PostgreSQL ядра.
- Все пути изменения сводятся к `POST /api/v1/apply`: `mfctl apply -f`, UI (редактирует тот же YAML) и `--apply-dir` при старте. Повторный apply того же спека не создаёт ревизию.
- Аннотация `manufacture.dev/managed-by: git` делает ресурс в UI доступным только на чтение.
- Настройки процесса ядра (адреса, ключи) задаются env, а не ресурсами.

**Альтернативы.** Только файлы: UI не может их менять. Только UI: нет диффа и ревью. CRD: требуют Kubernetes.
